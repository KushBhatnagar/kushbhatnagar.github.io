# blogsbykush

Source for **[blogsbykush.com](https://blogsbykush.com)**, Kush Bhatnagar's blog: *Learn. Build. Explain.*

Built with [Hugo](https://gohugo.io/) (Extended ≥ 0.146) and the [PaperMod](https://github.com/adityatelange/hugo-PaperMod)
theme (git submodule), deployed to GitHub Pages by `.github/workflows/hugo.yml`.

```bash
git submodule update --init --recursive
hugo server            # http://localhost:1313
```
